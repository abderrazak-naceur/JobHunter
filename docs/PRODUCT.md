# Product scope

## Public portfolio
Professional headline, summary, work experience, skills, selected projects and owner-controlled CV/contact links.

## Private workspace
- Dashboard with application and interview metrics
- Opportunities with company, role, location, salary range and source URL
- Pipeline: Saved, Applied, Screening, Technical interview, Offer, Rejected, Withdrawn
- Interview dates, contacts, notes and preparation checklist
- Job description documents and AI-generated analysis
- Academy courses, modules, resources and learning progress
- Career coach with skill-gap and learning recommendations

## Admin
Manage portfolio content, opportunities, application stages, interviews, documents, courses, learning paths and AI provider configuration.

## Initial search preferences
Roles: Senior .NET Developer, Full Stack Developer, Technical Lead. Location: Milan area, approximately 50 km. Work mode: remote or hybrid. Target gross annual salary: €40,000–€50,000+. Skills: C#, .NET, React, SQL Server, PostgreSQL, Azure and Docker. All preferences remain editable.

## Integrations
Use official APIs and permitted authorization flows where available. Otherwise support manual URL entry and user-initiated import. Do not implement prohibited scraping or credential collection.
